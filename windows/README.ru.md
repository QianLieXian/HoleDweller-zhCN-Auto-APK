**0.2.0 · Steam Windows r44** · [7z](https://github.com/QianLieXian/HoleDweller-zhCN-Auto-APK/releases/tag/v0.2.0-r44)

Закройте игру. Скачайте 7z версии Windows 0.2.0, полностью распакуйте и запустите **WindowsPatch.cmd**. Выберите **4. Русский**, затем папку с `HoleDweller.exe` и `data.win`. Оригинал сохраняется в `data.win.zhCN.original`; пункт **2. English** восстанавливает его. Между распознанными языковыми патчами проекта можно переключаться. Сохранения не изменяются. Несовместимые версии и изменённые MOD-файлы отклоняются.

1 464 записи; исходные клавиатура, мышь и вызовы Steam сохранены. Контекстный перевод GPT/Codex; независимая проверка носителями языка и полное прохождение каждого языка ещё не выполнены.
