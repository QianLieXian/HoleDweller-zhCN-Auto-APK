**0.2.0 · Steam Windows r44** · [7z](https://github.com/QianLieXian/HoleDweller-zhCN-Auto-APK/releases/tag/v0.2.0-r44)

ゲームを終了し、Windows 0.2.0の7zをすべて展開して **WindowsPatch.cmd** を実行します。**7. 日本語** を選び、`HoleDweller.exe` と `data.win` のあるフォルダーを指定してください。元のファイルは `data.win.zhCN.original` に保存され、**2. English** で戻せます。本プロジェクトの認識済み言語パッチ間では切り替えが可能です。セーブデータは変更しません。非対応版や互換性のないMOD変更済みリソースは拒否されます。

1,464項目を収録し、元のキーボード・マウス操作とSteam呼び出しを維持します。GPT/Codexによる文脈を踏まえた翻訳です。母語話者による独立レビューと各言語の全編プレイは未実施です。
