**0.2.0 · Steam Windows r44** · [7z](https://github.com/QianLieXian/HoleDweller-zhCN-Auto-APK/releases/tag/v0.2.0-r44)

Feche o jogo. Baixe o 7z da versão Windows 0.2.0, extraia tudo e abra **WindowsPatch.cmd**. Escolha **3. Português** e selecione a pasta com `HoleDweller.exe` e `data.win`. O patch usa português brasileiro. A cópia original é preservada em `data.win.zhCN.original`; a opção **2. English** restaura o original. É possível trocar entre idiomas reconhecidos pelo projeto. As partidas salvas não são alteradas. Recursos de outras versões ou MODs incompatíveis são recusados.

1.464 entradas; teclado, mouse e funções Steam originais preservados. Tradução contextual com GPT/Codex; revisão independente por falantes nativos e testes completos em cada idioma ainda pendentes.
