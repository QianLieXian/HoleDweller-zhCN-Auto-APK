# Hole Dweller / HoleDweller 汉化与多语言翻译补丁 · Windows & Android

**Hole Dweller（HoleDweller）非官方游戏翻译与本地化项目**，适用于 **Steam Windows r44**。提供 Windows 汉化及多语言补丁，并可在 Windows 上使用自己正版游戏的资源生成 Android APK。支持简体中文、原版英文、巴西葡萄牙语、俄语、西班牙语、德语、日语、法语、韩语和土耳其语。

Unofficial **Hole Dweller translation patches** for Windows and an **Android APK builder** for your own Steam r44 copy. Nine fan translations plus original English: 简体中文 · English · Português (Brasil) · Русский · Español · Deutsch · 日本語 · Français · 한국어 · Türkçe.

原游戏由 **ThighHG** 开发：[Hole Dweller 官方页面](https://thighhg.itch.io/hole-dweller)。本仓库提供社区翻译补丁和打包工具；仓库名称中的 `zhCN` 来自早期中文版本，目前已扩展为多语言项目。

## 使用

**Windows：** 退出游戏，解压补丁包，运行 **WindowsPatch.cmd**，选语言，再选游戏目录。首次安装备份原版，已知本项目语言可自动切换；选2还原英文。原有键鼠和Steam调用保留，安装器不访问存档。已修改的其他版本或MOD资源会被拒绝。

**安卓：** 解压打包器，运行 **Build-APK.cmd**，选语言和游戏目录。首次自动下载便携环境与运行器，支持7897代理，不设开机自启。生成的APK在 `output`；不同语言使用独立包名和存档。更新打包器时保留 `.local/个人构建签名.jks`。

## 常见问题

### Hole Dweller 汉化补丁在哪里下载？
下载上方 Windows Release 的 7z 附件，完整解压后运行 `WindowsPatch.cmd`。需要兼容的 Steam Windows r44 游戏；其他版本或经过第三方 MOD 修改的资源可能无法安装。

### 有没有 Hole Dweller 安卓版 APK 下载？
本项目提供 Android APK 打包器。玩家需要在 Windows 上使用自己拥有的兼容游戏资源生成 APK，公开 Release 不提供完整游戏 APK。安卓构建版本仍处于 alpha 阶段，具体设备要求与测试限制见[安卓说明](android/README.md)。

### 支持哪些翻译？英文也需要补丁吗？
目前有九种非官方翻译：简体中文、巴西葡萄牙语、俄语、西班牙语、德语、日语、法语、韩语和土耳其语。英文使用原版文本；Windows 菜单 2 可还原英文，Android 打包器可生成英文版本。

### 能反馈翻译错误或参与母语审校吗？
可以。请在 [Issues](https://github.com/QianLieXian/HoleDweller-zhCN-Auto-APK/issues) 提供语言、条目 ID 或原文、截图、建议译法和上下文。独立母语者逐行审校仍待进行。

## 翻译与验证

译稿由GPT网页High档及Codex结合上下文编写、修订，没有接入自动翻译服务；独立母语者逐行审校仍待进行。欢迎附条目ID、截图和建议反馈。

Windows新增语言已完成资源编译、差分往返、安装、切换、还原和版本拒绝检查；未完成逐语言完整游玩。安卓十语言APK通过构建、签名、对齐和资源检查，alpha.6尚未实机运行。详情见[Windows测试记录](windows/测试记录.json)和[安卓测试记录](android/测试记录.md)。
