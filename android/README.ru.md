# Hole Dweller — сборщик APK для Android

**Версия проекта: 0.2.0-alpha.6. Поддерживаемая игра: Steam Windows r44 с проверкой исходного файла.** Экспериментальный инструмент создаёт APK локально из вашей собственной копии игры. VM-код исполняется в нативной среде GameMaker для Android. Это не официальный порт.

## Сборка APK

1. Скачайте архив сборщика `.7z` из [Releases](https://github.com/QianLieXian/HoleDweller-zhCN-Auto-APK/releases). Распакуйте полностью в доступную для записи папку Windows, отдельно от игры.
2. Запустите **Build-APK.cmd** и выберите **4. Русский**.
3. При первом запуске недостающие переносимые инструменты загрузятся автоматически: около 144 МБ, затем около 32 МБ для среды Android. Проверяются суммы SHA256. Автозапуск Windows не создаётся.
4. Выберите папку Hole Dweller с `data.win`. Нужен поддерживаемый оригинал r44 либо резервный файл `data.win.zhCN.original`. Иные версии отклоняются.
5. Перенесите `output/HoleDweller-RU-Android-0.2.0-alpha.6.apk` на Android и установите.

Требуются Windows, PowerShell 5.1+, интернет для первой сборки и минимум 2 ГБ свободного места. Основная платформа — Android ARM64; x86_64 предусмотрена для эмулятора. Старые устройства и страницы памяти 16 КБ требуют дополнительных проверок. Прокси `127.0.0.1:7897` определяется автоматически; другой задаётся через `HD_ANDROID_PROXY`. Сохраните `tools` и `.local/runner-2024.14.apk`, чтобы не скачивать их снова.

## Управление

| Элемент | Действие |
| --- | --- |
| Касание сцены | Левая кнопка мыши |
| Стрелки / ПРОБЕЛ | Направление / исходное действие пробела |
| Q / E рядом со стрелкой вверх | Левая / правая кнопка в последней точке касания |
| Фиксация правой кнопки | Режим правого клика |
| Средний клик / фиксация | Средняя кнопка / постоянный режим |
| Колесо + / - | Прокрутка вверх / вниз; удерживайте для повтора |
| Меню / Растянуть / Кнопки | Настройки / заполнить экран / показать управление |
| Назад | Удержание возвращает на титульный экран; там удержание закрывает игру |

В меню есть масштаб внутреннего изображения 1×–4×, автоматический масштаб, 60/120, громкость и перезагрузка сцены для локальных MOD. Переключатель 120 не гарантирует реальные 120 Гц. F11/F12 требуют подтверждения. Удаление сохранения требует подтверждения и удержания; отпускание отменяет действие. Загрузка в Steam Workshop на Android недоступна.

## Перевод, проверки и обновление

Переводы подготовлены и отредактированы с GPT в режиме High по контексту, характеру персонажей и механикам, без автоматического сервиса перевода. Независимая построчная проверка носителями языка ещё не выполнена. Имена персонажей сохранены; текст внутри изображений может остаться исходным. Неполный каталог и повреждённое форматирование блокируют сборку.

Исправление зависания на пляже при встрече с Zaria подтверждено для alpha.4 на Lenovo TB-Q706F / Android 12. Это не означает полное прохождение alpha.6 на всех языках. Смотрите отчёт проверки конкретного релиза. В сообщении об ошибке укажите язык, версию, устройство, Android и шаги. `Collect-Crash-Logs.cmd` получает журналы по USB без root и без удаления сохранений. Перед публикацией проверьте журналы.

При обновлении сохраните `.local/个人构建签名.jks`: прежняя подпись позволяет обновить приложение без удаления. Языковые версии имеют разные пакеты и отдельные сохранения; автоматического переноса нет. Не публикуйте ключ, сохранения, личные журналы, `data.win` или APK с полной игрой. Предлагайте правки в `locales/ru.game.json` с ID, контекстом и объяснением. Новую версию игры нужно заново проверить и адаптировать.
