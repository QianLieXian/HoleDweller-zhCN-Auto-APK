# Hole Dweller 原生安卓汉化打包实验

**版本：0.2.0-alpha.4 · 适配 Steam Windows r44。**

在 Windows 上选择自己持有的游戏目录，工具加入简体中文汉化与触屏控制，再生成可安装的安卓 APK。使用 GameMaker ARM64 安卓运行器执行游戏 VM 字节码，不使用 Windows 模拟器，也不串流电脑。

🟢 已完成本地构建、APK 签名与对齐检查。此前 alpha.2 启动修复候选在 Android 12 x86_64 测试环境进入中文菜单、存档选择和开场对话；用户随后反馈了实体平板上的按键布局、显示与120Hz问题。  
🟢 alpha.4 修复沙滩遇见 Zaria 后的显卡死锁闪退：联想小新 Pad 12.6 Pro（Android 12）已覆盖安装，用户复测确认能完成感叹号后的角色剧情。完整游玩及其他设备仍需继续验证。

## 一键打包

1. 完整解压工具包，放在可写入的目录，例如“文档”，不要放在游戏目录内。
2. 双击 **一键打包APK.cmd**。
3. 选择自己的 Hole Dweller 目录，里面应有 `data.win`。目前只接受已适配的 Steam r44 原版，或本项目 0.1.0 汉化资源。
4. 等待完成。首次构建会下载约32 MB的固定版本运行器；本工具支持自动探测本机7897代理，也可使用系统代理。
5. 将 `output/HoleDweller-zhCN-Android-0.2.0-alpha.4.apk` 复制到手机安装。

工具已经携带便携 Java、Python、UndertaleModTool 和 APK 构建工具，不需要设置开机启动。运行器从指定上游版本下载并检查 SHA256。

支持 **64位 ARM 安卓手机和平板**；另含 x86_64 运行器供模拟器测试。清单最低 Android 5.0，但实际兼容性、旧安卓及16 KB页设备均需实测。横屏默认保持16:9，以设备实际绘制区域居中；左上角“拉伸”可切换铺满，支持不同屏幕尺寸。

## 手机上怎么操作

| 按钮或操作 | 用途 |
| --- | --- |
| 点击游戏画面 | 原版鼠标左键交互 |
| 上、下、左、右 | 方向输入与视角移动 |
| 空格 | 推进时间；对应场景中的动作、跳过或加速 |
| Q／E | 位于上箭头两侧，对应鼠标左／右键；作用在最近一次点击的游戏位置 |
| 右键锁 | 开启／关闭右键模式；开启后点击场景即为右键，亮色表示启用 |
| 中键 | 单次中键按下，按住时保持中键；对应场景的切换或镜头操作 |
| 中键锁 | 开启／关闭持续中键输入，亮色表示启用；锁定后拖动画面作为中键移动，不同时触发左键，不会每帧重复发送单击 |
| 滚轮上／下 | 滚动一档；按住可连续滚动 |
| 缩放 | 切换场景远近视角 |
| 返回 | 按住返回标题；标题界面按住退出 |
| 左上角“按键” | 显示／隐藏触屏控制，以免挡住界面 |
| 左上角“菜单” | 打开显示／声音、场景／资源、特殊功能三页菜单 |
| 左上角“拉伸” | 开关铺满屏幕；开时可能改变画面比例，关时保持原比例 |

没有将删档、重算角色属性或清除角色状态的危险快捷键放在触屏面板。

普通按键底色不透明度为18%，按下／锁定时45%。隐藏常驻按键后，按键、菜单和拉伸入口仍可用。

## 菜单与显示

| 菜单项 | 安卓中的作用 |
| --- | --- |
| 数字1／2／3 | 设置640×360、1280×720、1920×1080的内部渲染分辨率；安卓没有桌面窗口，不改变设备面板分辨率 |
| 数字4 | 保持全屏 |
| F1／F2／F3／F4 | 设置内部画面的1／2／3／4倍分辨率，保留原版部分场景的禁用条件 |
| 自动分辨率 | 根据当前绘制区域选择1～4倍；与拉伸开关独立，可随时改回手动 |
| P：120Hz | 切换原版120帧逻辑与60帧逻辑；修复被适配脚本强制关闭的问题，设置页面勾选可保留。实际屏幕刷新率受硬件、安卓系统和节电设置影响 |
| V：音效 | 每次降低一档，到底后循环回最高 |
| 空格+6 | 游玩中重载当前场景，供重新载入本地MOD；标题工坊上传需要Steam，在安卓显示不可用提示 |
| 资源作弊码 | 可用方向键手动输入↑↑↓↓←→←→；菜单也可发送相同方向序列，仅在游玩中使用 |
| F11／F12 | 清除怀孕状态／重算角色属性及相关状态，需要确认后执行 |
| Backspace | 仅特殊功能页提供；确认后长按4秒，再继续保持至原版删档计时完成。松手立即停止；不要用正常存档测试该功能 |

默认保持16:9，在其他比例屏幕上仍可能有必要的黑边。拉伸打开后会按当前绘制区域铺满，游戏画面、原版界面及触屏坐标一起变换，不裁掉内容。拉伸与分辨率设置保存在应用本地，下次启动继续使用。

## 汉化与平台功能

- 带入已有1,464条译文、中文显示名、像素字体和中文换行修复。
- 译文由 GPT 结合角色语气、触发情境和游戏机制逐条起草、润色并统一术语，没有接入自动机翻服务；属于 AI 辅助译稿，尚未经过独立人工逐句审校。第三方MOD新增台词不在本版覆盖范围内。
- 保留游戏内成就逻辑；屏蔽 Windows Steam 扩展调用。Steam 成就同步、云存档和创意工坊在线功能不提供。
- 本地MOD路径改为使用斜杠。安卓MOD导入入口和系统键盘尚未制作，请勿把它们视作已验证功能。
- 安卓使用应用自身的存档区域，不导入、不修改电脑存档。未请求联网、蓝牙、共享存储权限。
- 原版资源、电脑汉化资源、电脑存档均不会被打包器改写；只有生成目录中的副本会被处理。

## 本次修复：沙滩剧情闪退

alpha.3 在沙滩遇见 Zaria、开始对话时，联想平板日志两次出现 Adreno 显卡“Resource deadlock would occur”，随后进程被终止。换色着色器使用低精度浮点坐标累加；调色板位于4096像素纹理页较靠下的位置时，累加值可能因精度不足而不再变化，循环无法结束。

alpha.4 将换色扫描改为最多256行的整数循环，在支持的显卡上使用高精度计算，并检查无效步长。角色换色、头像、中文对话和原有触屏功能保留。原版调色板均低于此上限；自制MOD的调色板请不要超过256行。已用相同签名覆盖安装，未清除设备存档；用户确认沙滩角色剧情能正常完成。

## 测试与反馈

请先测试：能否安装→打开→中文主菜单→开场选项→进入游戏→触屏交互→推进一天→退出后重新进入。

若报错，请提供手机型号、安卓版本、发生步骤、完整报错截图。若直接闪退，日志不需要 root：在安卓设备的开发者选项打开 **USB 调试**，用数据线连接电脑，在设备上允许调试，再双击本工具的 **收集闪退日志.cmd**。脚本会启动游戏并记录20秒，结果放在 `.local/设备日志/日期时间`，不会自动上传，也不会清除存档。日志可能含路径及同时发生的其他应用错误，分享前请检查。没有找到设备时，先检查数据线、授权或厂商 USB 驱动。

本版修复了 alpha.1 的启动故障：运行器按旧包名查找 APK 资源，导致启动时 `Unable to locate assets`；另清除了安卓载入时无法解析的 Steam 函数表残留。同时关闭开发热重载连接，并修正对话逐字显示的越界警告。

测试环境与实体 ARM64 平板不同。已收到联想小新 Pad 12.6 Pro、Android 12 的 alpha.1 闪退反馈，以及后续按键、黑边和120Hz反馈。alpha.3 的沙滩闪退已通过 ADB 日志复现；alpha.4 已通过同一平板的剧情复测。未完成完整游玩、音频听感及保存后重进测试，详见 `测试记录.md`。此前测试时电脑发生意外重启，原因尚未确定；新增的模拟器虚拟化驱动已移除，本次未重新安装或启用，工具包不包含模拟器或虚拟化驱动。

本地 `.local/build/构建日志.txt` 可排查打包错误。`.local/个人构建签名.jks` 为本机生成的测试签名，请保留，否则以后生成的包可能无法覆盖安装旧包。签名使用公开的开发密码，仅用于个人测试，不是正式发行密钥；不要使用它签署其他重要应用。

## 后续更新

后续先补齐其他角色剧情、触屏与多点触控、保存后重进和声音的实机验证，再扩大设备测试范围。遇到新问题请保留完整日志及版本号，修改 `src/安卓适配.csx` 或 `src/触屏控制.gml` 后重新打包测试。游戏更新后需重新确认资源版本并制作对应汉化差分，不能直接跳过校验。升级打包器时保留本机 `.local/个人构建签名.jks`，以便覆盖安装并保留应用存档。


维护时，安卓源码位于仓库的 `android/src`；下载的完整7z内对应目录是 `src`。需要改译文时，先按项目首页的流程更新译文和汉化差分，再同步到安卓打包器的 `patch`，重新生成APK实测。每次发布都更新版本号、测试记录、README和7z校验文件，在 Releases 里保留旧版，方便比较和回退。

**覆盖更新：** 保留原打包器的 `.local/个人构建签名.jks`，将它放回新版工具相同位置，再重新构建。使用同一签名的APK可以覆盖安装；不要为解决签名不一致直接卸载旧版，以免丢失应用存档。工具源码仓库与公开7z都不会包含个人签名、设备日志或存档。
